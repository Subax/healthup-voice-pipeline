# LEGAL_REVIEW — 법적 검토 (개인정보·의료·AI·라이선스)

> **결론**
> 1. 가장 큰 부담은 **개인정보보호법**이다. 상담 내용은 민감정보(건강)일 가능성이 높아 별도 동의가 필요하다. 보호자 보고서는 제3자 제공 동의가 하나 더 필요하다.
> 2. **진단·치료로 보이는 기능과 표현을 넣지 않는다.** 넣으면 의료법 §27(무면허 의료행위), 의료기기, 고영향 AI 쪽으로 기운다. AI Hub KlueBERT(질환 유무 분류)가 이 경계에 걸렸다. 검증에서 작동하지 않아 쓰지 않기로 했다.
> 3. **AI 기본법 §31 사전 고지**는 지금 시행 중이다 (2026-01-22). 세션 시작 때 화면과 음성으로 "AI"임을 알려야 한다.
>
> **지금 할 일**: 판단 로그(`bench/results/endpoint_log/*.jsonl`)의 전사 저장을 운영 기본값에서 끈다. 그다음 동의 화면 초안을 만든다.

- 작성: 2026-10-21. 근거: 웹 조사 2건(법령·판례·라이선스) + 저장소 코드 확인
- **이 문서는 법률 자문이 아니다.** 출시 전 변호사 검토가 필요하다
- 조문은 주로 casenote.kr 현행 법령으로 확인했다. law.go.kr은 직접 열리지 않았다
- 확인하지 않은 내용은 "확인하지 않았다"로 표시했다. 맨 아래 목록에 모았다
- 전제: 설치 장소는 복지관·보건소 같은 공공장소일 수 있다 (확정 아님). 카메라 사용은 미정이다

1. 고령자 본인에게 §17 제공 동의와 §23 민감정보 동의를 따로 받는다
2. 본인이 보고서에서 뺄 항목을 고를 수 있게 한다
3. 학대 정황이 있으면 보호자 전송을 막는다. 가해자가 보호자일 수 있다 (노인복지법, §5)
4. 위기 상황은 정기 보고서로 보내지 않는다. 별도 즉시 경로를 쓴다

- 권고: **카메라를 쓰지 않는다.** 쓰게 되면 법률 검토를 먼저 한다

### 5.1 ⚠️ AI Hub 제공 모델과의 충돌

사용자는 71806의 제공 모델 2개를 모두 쓰기로 했다 (2026-10-21). 검토 결과 하나가 충돌한다.

| 모델 | 기능 | 법적 위험 | 권고 |
|---|---|---|---|
| KlueBERT 분류기 | 상담 스크립트 → 우울·불안·중독 질환 유무 0/1 | **높음.** 질환 판별은 진단 목적으로 볼 수 있다 → 의료기기, 의료법 §27, 고영향 AI | 선택지 아래 |
| 요약 모델 (polyglot-ko-12.8b) | 상담 요약 (주요 증상·위험요인 등) | 중간. "증상" 같은 의료 표현이 문제 | 보호자용 일상어 형식으로 바꿔 쓴다 |

KlueBERT 선택지:
1. **(추천) 제품에 넣지 않는다.** 데이터셋 분석·연구용으로만 쓴다
2. 제품에 넣되 점수를 사용자·보호자에게 보이지 않는다. 내부 "상담센터 연결 권유" 신호로만 쓴다. 이 경우도 진단 목적 해석 위험이 남는다. 법률 검토 후 결정한다
3. 의료기기 경로로 간다 (임상시험·허가). 이 프로젝트 일정에 맞지 않는다

**사용자 결정 (2026-10-21, 최종)**: 우울 분류기는 쓰지 않는다. 71806 라벨은 **평가용으로만** 쓴다.
위기 감지는 Kanana Safeguard + 키워드 규칙 + 109·119 안내로 한다. 이 결정으로 질환 판별 기능이 제품에서 빠진다.
(앞선 결정 "점수를 LLM 내부 참고로 쓴다"는 아래 검증 결과 때문에 취소했다.)

**검증 결과 (2026-10-21, 검증 세트 174세션, GB10 GPU)**: 제공 모델은 **입력과 무관하게 거의 같은 점수**를 낸다.

| 모델 | 이진 정확도 | 평균 점수 (양성 / 음성) | 일상 문장 vs 우울 문장 |
|---|---|---|---|
| 우울 | 0.68 | 1.27 / 1.27 | 1.27 vs 1.31 |
| 불안 | 0.67 | 1.26 / 1.26 | 1.24 vs 1.28 |
| 중독 | 0.68 | 1.23 / 1.22 | 음주 문장 1.24 |

- 정확도 0.68은 양성 비율(52/76)과 같다. 모델이 모두 "양성"으로 답한 결과다
- 가중치는 정상 로드했다 (누락 키 없음). 학습 단계에서 평균값으로 붕괴한 것으로 본다
- 원 학습 코드는 세션 전체 대본을 앞 512토큰에서 자른다. 세션 첫 몇 분(인사)만 본 셈이다
- **결론: 이 모델은 신호로 쓸 수 없다.** 제품에 넣지 않는다
