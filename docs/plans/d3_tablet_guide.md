
## 2. 태블릿에 CA 인증서(`certs/ca.pem`) 설치

모바일 브라우저(Chrome, Safari 등)에서 마이크 권한(`getUserMedia`)을 정상 획득하려면 안전한 보안 컨텍스트(HTTPS)가 필수입니다. 자체 서명 경고를 방지하기 위해 생성된 로컬 루트 CA(`certs/ca.pem`)를 태블릿에 설치해야 합니다.

### 2.1 인증서 파일 태블릿 전달
* `certs/ca.pem` 파일을 메일, 구글 드라이브, 카카오톡 나에게 보내기, 또는 USB 연결 등으로 태블릿 다운로드 폴더에 복사합니다.
* (선택) 로컬 PC에서 임시 파일 서빙:
  ```bash
  # 호스트에서 실행 (예: 포트 8792)
  python3 -m http.server 8792 --directory certs
  # 태블릿 브라우저에서 http://192.168.0.35:8792/ca.pem 접속하여 다운로드
  ```

### 2.2 기기별 인증서 설치 절차

#### Android (Samsung Galaxy Tab 등)
1. **설정** 앱 실행
2. **보안 및 개인정보 보호** (또는 생체 인식 및 보안) → **기타 보안 설정**
3. **인증서 설치** (또는 암호화 및 사용자 인증정보 → 인증서 설치)
4. **CA 인증서** 선택 (경고 메시지 나타나면 "그래도 설치" 선택)
5. 다운로드한 `ca.pem` 파일 선택 후 설치 완료
6. 인증서 이름: `HealthUp Local CA` 확인

#### iPadOS / iOS (Apple iPad)
1. 태블릿 Safari에서 `ca.pem` 열기 → **프로파일 다운로드됨** 알림 확인
2. **설정** → 상단 **프로파일이 다운로드됨** 선택 (또는 일반 → VPN 및 기기 관리)
3. `HealthUp Local CA` 프로파일 **설치** 클릭 및 암호 입력
4. **인증서 신뢰 활성화 (필수)**:
   - **설정** → **일반** → **정보** → 맨 아래 **인증서 신뢰 설정**
   - "루트 인증서 전체 신뢰 활성화" 섹션에서 **HealthUp Local CA** 스위치를 **ON(활성화)**으로 켬

## 3. 태블릿 접속 방법

1. 태블릿과 개발 서버 PC가 **동일한 Wi-Fi 공유기(192.168.0.x)**에 연결되어 있는지 확인합니다.
2. 태블릿 브라우저(Chrome 또는 Safari)를 엽니다.
3. 주소창에 아래 URL을 입력하여 접속합니다:
   ```
   https://192.168.0.35:8080/?t=healthup-d3
   ```
4. 주소창 좌측에 **자물쇠 아이콘(보안 연결)**이 정상 표시되는지 확인합니다.

## 4. 7대 실기 점검 항목 및 합격 기준

`webapp_plan.md` §5 D3에 명시된 7대 검증 항목을 순서대로 점검하고 기록합니다.

|:---:|:---|:---|:---|
| **1** | **HTTPS 접속** | 주소창 URL 접속 확인 | 보안 경고(SSL 오류) 없이 화면이 정상 로드되고 녹색/정상 자물쇠가 뜸 |
| **2** | **첫 터치 뒤 마이크** | 화면 첫 터치 안내 오버레이 터치 | 브라우저 마이크 권한 팝업에서 "허용" 선택 후 상단에 `"마이크 대기 중"` 배지 점등 |
| **3** | **음성 시작·종료** | ① 태블릿 마이크에 대고 `"시작하자"` 발화<br>② 대화 후 `"종료하자"` 발화 | ① `"AI 마음 건강 도우미입니다"` 고지 음성 재생되며 진행 모드 전환<br>② `"대화를 종료합니다"` 안내 후 대기 상태 복귀 |
| **4** | **음성 모드 전환** | 태블릿 마이크에 대고 `"개발 모드로 바꿔 줘"` 및 `"데모 모드로 바꿔 줘"` 발화 | ① 화면에 개발 패널(로그, 세부 지표) 즉시 노출<br>② 데모 모드로 복귀 시 간소화 화면으로 즉시 전환 |
| **5** | **데모 모드 개별 기능 토글<br>(AI 고지 경고 포함)** | ① 우측 상단 `⚙️` 설정 버튼 클릭하여 개별 스위치(wake, face 등) 토글<br>② 음성으로 `"대기 청취 꺼 줘"` 발화<br>③ `"AI 고지 숨겨 줘"` 발화 또는 토글 끄기 시도 | ① 각 기능이 개별적으로 켜지고 꺼짐<br>② 음성 명령 즉시 반영<br>③ **AI 고지 해제 시 법적 필수 고지 경고 팝업 및 확인 질문** 작동 |
| **6** | **재연결 뒤 모드·설정 유지** | 태블릿 브라우저 새로고침(F5) 또는 Wi-Fi 일시 해제 후 재연결 | 이전 설정(선택된 모드, 개별 토글 상태)이 초기화되지 않고 유지됨 |
| **7** | **RTT P50 기록** | 상단 상태 표시줄의 RTT 값 확인 및 20회 측정 | Wi-Fi 환경 RTT P50 수치 기록 (권장: P50 ≤ 20ms) |

## 5. 네트워크 지연(RTT) 벤치마크 점검 (호스트 측정)

호스트 서버에서 `bench/net_probe.py`를 실행하여 네트워크 및 소켓 응답 지연 기준선을 확인합니다:

```bash
.venv/bin/python bench/net_probe.py \
  --url https://192.168.0.35:8080/ws \
  --token healthup-d3 \
  --cacert certs/ca.pem
```

* 실측 기준선 (2026-10-23 기준):
  - ping RTT: P50 **0.59ms**, P90 **0.64ms**, 최대 **1.13ms**
  - text_input → 첫 오디오 프레임: **0.8ms** (Mock 모드 기준)

## 6. 문제 해결 (FAQ)

1. **"연결이 비공개로 설정되어 있지 않습니다" (NET::ERR_CERT_AUTHORITY_INVALID) 오류**:
   - 태블릿에 `ca.pem`이 정상 설치되지 않았거나 신뢰 설정이 켜지지 않은 상태입니다. 2.2절을 다시 확인해 주세요.
2. **마이크 권한 요청이 뜨지 않음**:
   - 브라우저 사이트 설정에서 해당 IP(`192.168.0.35`)의 마이크 권한이 "차단"되어 있는지 확인 후 "허용"으로 변경합니다.
3. **태블릿에서 페이지가 열리지 않음 (접속 불가)**:
   - 태블릿이 PC와 같은 Wi-Fi 망(`192.168.0.x`)에 있는지 확인합니다.
   - 호스트 PC의 방화벽(ufw / iptables)에서 8080 포트가 차단되어 있지 않은지 확인합니다.
