# D1 음성 명령 녹음 평가 사용자 가이드 (`webapp_plan.md` §5 D1 · §7 · `bench/intent_wav_script_ko.tsv`)

> **목적**: 실제 마이크로 한국어 음성 명령 200문장을 녹음하여, SenseVoice STT와 규칙 기반 의도 분류기의 **실제 음성 명령 재현율(목표 ≥ 90%)**, **되돌릴 수 없는 명령 오실행(0건)**, **위기 표현 오판(0건)**을 검증하고, STT 표기 변형을 수집하여 D1b 규칙 보강에 활용한다.  
> **진행 조건**: vLLM(healthup-llm)이나 GPU 컨테이너 없이 CPU(SenseVoice STT)만으로 구동된다.

---

## 1. 녹음 방법 (환경·마이크·발화 요령)

1. **녹음 환경**:
   - 조용한 방 (배경 소음 권장 < 40dBA, 선풍기·에어컨·PC 팬 소음 및 외부 소음 최소화).
   - 반향(에코)이나 울림이 적은 환경.
2. **마이크 설정**:
   - **10/30 데모에 실제로 사용할 마이크** (태블릿 내장 마이크 또는 USB 마이크) 사용.
   - 마이크와의 거리: 약 30~50cm (실제 데모 사용 거리 유지).
3. **오디오 포맷 규격**:
   - **포맷**: 16-bit Linear PCM WAV (`.wav`)
   - **샘플 레이트**: 16,000 Hz (16 kHz)
   - **채널**: Mono (단일 채널)
   *(다른 샘플 레이트나 스테레오로 녹음되어도 평가 스크립트가 16kHz 모노로 자동 리샘플/다운믹스하지만, 원본 16kHz 모노 녹음을 권장합니다.)*
4. **발화 방법 및 어조**:
   - 대본에 적힌 문장을 고령자 또는 일반 사용자가 기기에 대화하듯 **자연스러운 구어 억양과 보통 속도**로 낭독합니다.
   - 발화 시작 전 0.2~0.3초, 발화 끝난 뒤 0.2~0.3초 정도의 짧은 무음 여유를 두고 녹음합니다.
   - **상태별 맥락 고려 발화**:
     - `idle` (001~010 시작 명령): 대기 중인 기기를 부르듯 또박또박 발화 ("시작하자", "안녕하세요").
     - `speaking` (011~020 정지 명령): 봇이 말하는 도중 끊는 상황을 연상하며 발화 ("잠깐만", "멈춰", "그만").
     - `confirming` (081~100 확인/거절): 확인 질문("...할까요?")에 대답하는 톤으로 발화 ("네", "아니요", "취소").
     - `CRISIS` (191~200 위기 표현): 연기 발화 ("다 끝내고 싶어", "그만 살고 싶어" 등 10문장).

## 2. 파일 이름 규칙 (대본 매핑 및 저장 위치)

- **저장 디렉터리**: `bench/results/intent_wav/`
- **녹음 대본 파일**: `bench/intent_wav_script_ko.tsv` (총 200문장)
- **파일명 형식**: `bench/intent_wav_script_ko.tsv`의 **3번째 열에 지정된 파일명**을 그대로 사용합니다.
  - 형식: `<3자리번호>_<의도명>_<표현번호>_r<회차>.wav`

### 문장 구성 요약 (총 200개)

| 분류 | 번호 범위 | 의도 목록 | 구성 | 수량 |
|---|---|---|---|---|
| **[1] 기본 명령 10종** | 001 ~ 100 | `SESSION_START`, `STOP_SPEAKING`, `REPEAT_BOT`, `REDO_USER`, `RESET`, `SESSION_END`, `MODE_DEV`, `MODE_DEMO`, `CONFIRM_YES`, `CONFIRM_NO` | 의도당 5문장 × 2회(r1, r2) | **100개** |
| **[2] 기능 토글 7종** | 101 ~ 170 | `CAMERA_ON`, `CAMERA_OFF`, `WAKE_ON`, `WAKE_OFF`, `DEV_INFO_ON`, `DEV_INFO_OFF`, `UI_BADGE_TOGGLE` | 의도당 5문장 × 2회(r1, r2) | **70개** |
| **[3] 비명령 대화문** | 171 ~ 190 | `CHAT` (일상 대화 및 건강 상담 문장) | 20문장 × 1회 | **20개** |
| **[4] 위기 표현** | 191 ~ 200 | `CRISIS` (시연자 연기 표현) | 10문장 × 1회 | **10개** |
| **합계** | **001 ~ 200** | | | **총 200개** |

### 주요 파일명 예시

- `001_SESSION_START_1_r1.wav` ("시작하자" 1회차)
- `002_SESSION_START_1_r2.wav` ("시작하자" 2회차)
- `013_STOP_SPEAKING_2_r1.wav` ("멈춰" 1회차)
- `041_RESET_1_r1.wav` ("처음부터 다시" 1회차)
- `051_SESSION_END_1_r1.wav` ("대화 끝낼게요" 1회차)
- `101_CAMERA_ON_1_r1.wav` ("카메라 켜 줘" 1회차)
- `171_CHAT_01.wav` ("그만 좀 하라고 했는데 아들이 계속 잔소리를 해요")
- `191_CRISIS_01.wav` ("다 끝내고 싶어")

*(일부만 먼저 녹음하고 실행하더라도, 누락된 파일은 자동으로 건너뛰고 목록으로 보고되므로 점진적으로 녹음·측정할 수 있습니다.)*

## 3. 개발 전용 녹음 웹 페이지 (`bench/d1_recorder.py`, 포트 8791)

200문장을 일일이 파일명으로 저장하는 번거로움을 줄이기 위해, 브라우저에서 스페이스바만 눌러 한 문장씩 바로 녹음·저장할 수 있는 개발 전용 녹음 웹 페이지를 제공합니다.

### 1) 녹음 서버 기동 명령 (1줄)

```bash
.venv/bin/python bench/d1_recorder.py --port 8791
```

*(서버가 이미 백그라운드로 켜져 있는 경우 재실행하지 않고 브라우저 접속만 하시면 됩니다.)*

### 2) 접속 주소 및 사용 방법

- **브라우저 접속 URL**: **`http://127.0.0.1:8791/`**  
  *(Chrome 등 최신 브라우저는 `localhost`/`127.0.0.1` 루프백 접속을 보안 컨텍스트로 인정하므로 별도 인증서 없이 마이크가 즉시 동작합니다.)*
- **조작 요령**:
  1. 페이지 진입 후 브라우저 마이크 권한을 허용합니다.
  2. 화면 중앙에 표시되는 발화 문장(예: **"시작하자"**)을 확인합니다.
  3. **`Space` 키**를 눌러 녹음을 시작하고, 문장을 말씀하신 뒤 다시 **`Space` 키**를 누릅니다.
  4. 자동으로 **16kHz 모노 16bit Linear PCM WAV**로 인코딩되어 `bench/results/intent_wav/<파일명>`으로 저장되고 다음 문장으로 넘어갑니다.
  5. **`P` 키** 또는 `[▶️ 다시 듣기]` 버튼으로 방금 녹음된 오디오 품질을 청취할 수 있습니다.
  6. 이미 녹음된 파일은 **`✅ 녹음 완료`** 상태로 표시되며, **`[⏭️ 다음 미녹음 문장]`** 버튼을 누르면 건너뛰어 녹음되지 않은 항목으로 즉시 이동합니다 (언제든 중단 후 이어 녹음 가능).

## 4. 평가 실행 명령 1줄

녹음이 완료되면(또는 일부 녹음 후 중간 확인 시), 저장소 루트에서 아래 명령 **1줄**을 실행하여 음성 인식 및 의도 분류 평가를 수행합니다:

```bash
.venv/bin/python bench/intent_eval.py --wav-dir bench/results/intent_wav
```

### 유용한 추가 옵션
- 상세 오인식 내역 출력:
  ```bash
  .venv/bin/python bench/intent_eval.py --wav-dir bench/results/intent_wav -v
  ```
- Qwen3-ASR(GPU 서버 가동 중일 때) 비교 측정:
  ```bash
  .venv/bin/python bench/intent_eval.py --wav-dir bench/results/intent_wav --stt qwen3asr
  ```

## 5. 보고할 것

측정이 완료되면 터미널 화면 출력과 함께 생성된 결과 파일(`bench/results/intent_wav_<YYYYMMDD>.txt`)에서 아래 **5가지 항목**을 보고합니다:

1. **녹음 파일 적재 수**:
   - 예: 전체 200개 중 200개 완료 (또는 누락 M개)
2. **명령 재현율 (Command Recall)**:
   - 합격 기준: **≥ 90.0%** (예: `153/170 (90.0%)`)
3. **되돌릴 수 없는 명령 / 법적 경고 명령 오실행 건수**:
   - 합격 기준: **0건** (`RESET`, `SESSION_END`, `MODE_DEV`, `CAMERA_ON`, `show_ai_notice=False` 오실행 여부)
4. **위기 표현 중 명령 오판 건수**:
   - 합격 기준: **0건** (10개 중 명령 판정 발생 여부)
5. **오인식 세부 내역 및 STT 전사 오류**:
   - 오인식된 문구의 STT 전사 텍스트와 실제 분류 결과 (D1b 정규식 및 조사/구어 변형 보강용).
