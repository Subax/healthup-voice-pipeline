# 상담 데이터 한국어 번역 계획

- 작성: 2026-11-02 (Grok)
- 상태: 계획만 있음. MediRA 본평가와 A14가 끝난 뒤 시작한다.
- 데이터 위치: `/mnt/t7/datasets/counseling/` (atom T7 SSD)
- 번역 결과 위치: `/mnt/t7/datasets/counseling_ko/` (원본 폴더는 건드리지 않는다)

## 1. 목표

중국어와 영어 상담 데이터를 한국어로 옮겨 HealthUp 상담 모델 튜닝에 쓴다. 번역체가 튜닝에 배지 않게 자연스러운 한국어 구어체로 옮긴다.

## 3. 줄이기 규칙

1. 같은 내용 지우기: 정규화한 본문의 해시로 중복을 뺀다.
2. SMILE은 대화 55,165개 가운데 1만 개를 무작위로 뽑는다(시드 고정). 품질 점검을 해 보고 늘릴지 정한다.
3. 감정 라벨, 전략 이름처럼 짧은 칸은 번역하지 않고 정해 둔 표로 바꾼다.
4. 번역 전에 위기 표현(자해, 자살)이 든 대화를 따로 표시한다. 이 대화는 검수를 꼭 거친다.

## 4. 번역 방법

- 모델: atom의 Qwen3.8-27B (vLLM). MediRA가 8002를 다 쓴 뒤에 돌린다.
- 단위: 대화 하나를 한 번에 번역한다. 앞뒤 흐름과 호칭을 맞추기 위해서다.
- 지침:
  - 상담사는 존댓말, 내담자는 원문 말투에 맞춘다.
  - 이름, 지명은 한국식으로 바꾸지 않고 그대로 둔다.
  - 문화가 달라 어색한 표현은 뜻이 같은 한국어 표현으로 옮긴다.
  - 원문 구조(역할, 턴 순서, JSON 칸)는 바꾸지 않는다.
- 출력 형식: 원본과 같은 칸에 `text_ko`를 더한 JSONL. 원문, 출처 폴더, 원본 줄 번호를 함께 남긴다.
- 실패 처리: JSON이 깨지거나 길이 비율이 0.4 미만 또는 2.5 초과면 한 번 더 번역하고, 그래도 안 되면 버린다.
- 이어 하기: 처리한 번호를 기록해 끊겨도 이어서 돌린다.

## 5. 검수

1. 자동 검사: 한글 비율, 남은 중국어 또는 영어 비율, 길이 비율.
2. 사람 검수: 데이터마다 50개씩 뽑아 한별님이 본다(자연스러움, 뜻 맞음 각 1~5점).
3. 위기 표현 대화는 모두 검수 목록에 넣는다.
4. 평균 4점 아래인 데이터는 지침을 고쳐 다시 번역하거나 튜닝에서 뺀다.

## 6. 일정 추정

- SMILE 표본까지 합쳐 대략 40만 발화. 처리 속도는 시범 1,000개로 잰 뒤 이 문서에 적는다.
- 순서: 시범 1,000개, 검수, 지침 고치기, 전체 번역, 검수, 튜닝 데이터 합치기.
